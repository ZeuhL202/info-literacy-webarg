# ひかり町デジタル探偵団

文部科学省「[情報モラル教育ポータルサイト](https://www.mext.go.jp/zyoukatsu/moral/)」の教材をもとに、小学4〜5年生が情報モラルを物語の中で体験できる Web の ARG(代替現実ゲーム)です。プレイヤーは画面上の「学習用タブレット」を操作し、チャット・検索・AI・学級新聞などのアプリを行き来しながら、5つの事件を解きます。

| 章 | 題材 | もとにした教材 |
| --- | --- | --- |
| 1 | ネットのうわさを確かめる | 動画教材㉕「本当か確かめよう!ネット検索編」 |
| 2 | 文字だけのやりとりで起きる誤解 | 動画教材⑳「思ったままSNSに送信しただけなのに」 |
| 3 | 生成AIとのつきあい方 | 動画教材㉘「全部正しいの?生成AIって」 |
| 4 | 著作物と写真の公開 | 動画教材⑱「著作物の公開」 |
| 5 | パスワードと個人情報を守る | 動画教材⑲「学習用タブレットの上手な使い方」 |

先生・保護者向けのねらいと話し合いの問いは、アプリ内の `#/teacher` ページにあります。

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェックとビルド(dist/)
```

動作確認では `?speed=10` を URL につけると、メッセージが10倍の速さで届きます。進みぐあいはブラウザの localStorage にだけ保存され、外部には送信しません。

物語の文章は `src/content/` にまとめてあります。ふりがなは `{漢字|かんじ}` の形で書くと表示されます。

## パスワード付きでの公開(GitHub Pages)

GitHub Pages のサイトはだれでもアクセスできるため、ビルド結果を1つの HTML にまとめてパスワードで暗号化(PBKDF2 + AES-GCM)し、パスワード入力画面だけを公開します。正しいパスワードを入れたときだけ、ブラウザの中で復号されてゲームが始まります。

```sh
SITE_PASSWORD=8文字以上のパスワード npm run build:protected   # dist-protected/ に出力
```

`main` ブランチに入ると、GitHub Actions が自動で公開します。最初に一度だけ、リポジトリで次の設定をしてください。

1. Settings → Secrets and variables → Actions で、`SITE_PASSWORD` という名前のシークレットにパスワードを登録する
2. Settings → Pages の「Build and deployment」で、Source を「GitHub Actions」にする

パスワードを変えたいときは、シークレットを更新して Actions の「Build and deploy」を手動で実行し直します。
